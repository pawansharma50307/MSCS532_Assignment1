# MSCS532_Assignment1

## Insertion Sort in Monotonically Decreasing Order

### Description
This program makes use of the Insertion Sort algorithm written in Python to arrange numbers in descending order.

### How to Run
Make sure Python is installed.

Run the following command:

python insertion_sort.py

### Sample Output
Original array: [41, 15, 42, 18, 23, 24, 5, 16]
Sorted array (decreasing order): [42, 41, 24, 23, 18, 16, 15, 5]
